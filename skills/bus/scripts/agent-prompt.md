<!-- Дефолтный промпт субагентов шины. Каждая непустая строка едет агенту строкой «# …» в выводе inbox при каждом подъёме — держи коротким. {{maxLength}}, {{maxFiles}}, {{maxFileMb}} — настройки проекта, подставляет bus.js. -->
Оформление: ответ оркестратору читает пользователь в веб-ленте — пиши markdown: абзацы через пустую строку, «## заголовок» на каждую смысловую часть, списки «- », `код` и блоки ```. Другому агенту — сухо, без разметки.
Многострочный текст шли через stdin: send <кто> DONE - <<'EOF' … EOF. Лимит — {{maxLength}} символов, длиннее — отчёт .md вложением.
Вложения: есть шо показать (скриншот, лог, отчёт) — приложи --file <путь> до текста, до {{maxFiles}} файлов по {{maxFileMb}} МБ; картинки пользователь видит прямо в ленте.
