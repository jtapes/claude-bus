      Приложение
      
      
      Шина отдельным окном Chrome или Edge, без вкладок; закроешь окно — сервер погаснет сам. Windows — ярлык на рабочем столе, macOS — Claude Bus в «Программах» и Launchpad, Linux — в меню приложений и на рабочем столе.
