# bus: веб-интерфейс

`bus.js ui [--port N] [--no-open] [--app]` — сервер на `127.0.0.1:4780` (занят — следующий порт). Запускай с `run_in_background`, пользователю отдай адрес из вывода; без вкладки гаснет сам через 15 минут.

- `--app` — отдельным окном Chrome или Edge без вкладок, с прошлыми размером и местом (`app-window.json` в каталоге шины; зум помнит сам браузер); закрыли окно — сервер гаснет через 10 с. `bus.js setup` после установки или первый запуск шины (`ui`, `init`, автоподключение) ставит ярлык «Claude Bus», он и открывает окно: Windows — на рабочем столе и в «Пуске» (с AppUserModelID окна Chrome/Edge — закреплённое на панели задач окно остаётся «Claude Bus» с его иконкой), macOS — `~/Applications/Claude Bus.app` (Launchpad, Spotlight), Linux — меню приложений и рабочий стол. Удалил и просит вернуть — `bus.js ui --shortcut` (или кнопка в ⚙).

- Рабочий каталог (от чьего оркестратора пишем, чьи настройки) — клик по пути в шапке: закреплённые, проекты шины, недавние, путь или обзор папок. Каталог не в шине подключается сам — первым сообщением, новым агентом или сохранением настроек проекта, именем папки (до того шапка пишет «подключится с первым сообщением»). Домашнюю папку и `~/.claude` не подключить — там только выбрать другой каталог. Каталог один на сервер — сменится во всех вкладках. `bus.js ui` из другого каталога-проекта при живом UI переключает его и выходит (`UI уже поднят, переключил…`); из домашней папки (ярлык) UI стартует в последнем выбранном каталоге.
- `@` в поле сообщения — выпадашка с файлами и папками проекта (с учётом `.gitignore`), выбор вставляет `@путь`: агент откроет файл сам, это не вложение. То же — кнопка-папка слева от скрепки.
- Пишет пользователь от имени оркестратора, и отвечают агенты оркестратору — адресата-человека в шине нет.
- Агента «не в шине» пользователь заводит сам первым сообщением из UI; там же он создаёт локальных агентов, правит роли (в том числе через ИИ) и удаляет локальных. Просит «создай агента» в чате — делай по `references/roles.md`.
- У выбранного агента над лентой — вкладки его диалогов с пользователем: «+» — новый диалог (агент начнёт с чистой истории), «×» — закрыть в историю (часы рядом с «+»: открыть или стереть насовсем). Закрытие — только вид страницы (`.claude/bus/closed.json` проекта), журнал цел. Ответ агента и `send` из чата уходят в текущий диалог — тот, куда пара писала последней, даже закрытый: он тогда снова открывается вкладкой; `history <оркестратор>` агенту отдаёт только его. На вкладке — процент окна контекста последнего фонового запуска агента в этом диалоге; в шапке — лимиты аккаунта 5ч/7д, как в строке статуса. У ответа агента из фонового запуска справа в шапке — «≈N» токенов, потраченных запуском (без чтения из кэша), раскладка в подсказке.
- Лента рендерит markdown и превью картинок (прочие вложения — чипом): длинное пользователю оформляй.
- Блок «К этим сообщениям:» с цитатами (`> **кто → кому** · время · тип`) в сообщении пользователя — сообщения, которые он выделил в ленте и на которые указывает: отвечай про них, в `history` их не ищи; вложения там — путями.
- Под сообщением, с которого агент начал последний фоновый запуск, — отметка: «работает 1:24» с кнопкой «Остановить», «остановлен» или «упал» с «Продолжить» (та же сессия claude), «отработал · N с · ≈N ток.». Пока получатель работает, у формы есть галочка «btw — вбросить сейчас»: сообщение дойдёт посреди хода, а не после конца работы. Из чата то же самое — `send --btw`, `stop`, `resume`.
- Пока агент работает, под отметкой «работает» — его живой ход: текст между шагами и вызовы инструментов (последние 6 строк, клик — все 30), в списке слева под «работает…» — последняя строка. Агент кончил — блок исчезает, в историю ход не пишется.
- Галочка «самоправка роли» (получатель — субагент; не снимается, пока не снимешь сам): после `DONE` агент предлагает правку роли — в списке «разбирает свою работу…», затем «предлагает правку роли»; карандаш открывает редактор с черновиком и diff. «Сохранить» — принять, «Отклонить правку агента» — снести черновик, «Откатить» — форма к роли на диске. Устройство — `references/roles.md`, «Самоправка роли».
- Шестерёнка в шапке — настройки проекта UI (те же, что `settings` в `references/admin.md`); из чата менять — только по просьбе пользователя.
- Фон страницы (видео под стеклом) пользователь выбирает там же, плитками вверху панели, а ползунком «Затемнение» под ними — плотность стекла над видео; это настройки браузера, не проекта — из чата их не поменять.
- Строка `[bus] Ответы агентов пользователю в UI … masha — DONE ×2` во входящих — ответы, которые пользователь читает в ленте (диалог с агентом он ещё не открыл; открыл — сюда они не приходят). Ничего не делай и агенту не отвечай; пользователь спросил, что ответили, — `history <кто>`.
- Медная кнопка «Обновить до v…» в шапке — вышел релиз шины новее установленной (проверка — раз при старте UI, только у копии с `release.json`). Жмёт пользователь: файлы `skills/bus` заменятся, копия старых — в `skills/bus.backup`, хуки в `settings.json` не трогаются. После — плашка с кнопкой «Перезапустить»: сервер поднимет себя заново на новом коде, демон расписания — тоже. Сам не перезапускай, пока пользователь не попросит; кнопки нет (старая версия) — `bus.js ui` заново и `pm2 restart bus-scheduler`, если расписание включено. Пока агент работает в фоне, обновление не ставится.
