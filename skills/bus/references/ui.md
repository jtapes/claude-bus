# bus: веб-интерфейс

`bus.js ui [--port N] [--no-open]` — сервер на `127.0.0.1:4780` (занят — следующий порт). Запускай с `run_in_background`, пользователю отдай адрес из вывода; без вкладки гаснет сам через 15 минут.

- Пишет пользователь от имени оркестратора, и отвечают агенты оркестратору — адресата-человека в шине нет.
- Агента «не в шине» пользователь заводит сам первым сообщением из UI; там же он создаёт локальных агентов, правит роли (в том числе через ИИ) и удаляет локальных. Просит «создай агента» в чате — делай по `references/agents.md`.
- Лента рендерит markdown (заголовки, списки, `код`, блоки кода, цитаты, ссылки) и показывает картинки-вложения превью — пишешь пользователю в ленту длинное, оформляй; прочие вложения — чипом со скачиванием.
- Под сообщением, с которого агент начал последний фоновый запуск, — отметка: «работает 1:24» с кнопкой «Остановить», «остановлен» или «упал» с «Продолжить» (та же сессия claude), «отработал · N с · ≈N ток.». Пока получатель работает, у формы есть галочка «btw — вбросить сейчас»: сообщение дойдёт посреди хода, а не после конца работы. Из чата то же самое — `send --btw`, `stop`, `resume`.
- Галочка «самоправка роли» в форме (видна, когда получатель — субагент; на одно сообщение): после `DONE` агент в той же сессии разбирает свою работу и предлагает правку роли. У агента в списке — «разбирает свою работу…», затем «предлагает правку роли»; карандаш открывает редактор уже с черновиком в форме — diff «было → стало» и пояснение агента, как после «Переписать с ИИ». «Сохранить» — принять (можно поправив руками), «Отклонить правку агента» — снести черновик, «Откатить» — вернуть форму к роли на диске, черновик остаётся. Сообщение с галочкой помечено в ленте «самоправка». Устройство — `references/agents.md`, «Самоправка роли».
- Шестерёнка в шапке — настройки проекта, от чьего имени открыт UI: лимит подъёмов в час, таймаут, длина сообщения, вложения, `history`, пороги расписания и веса переписки, модели сжатия и правки роли. У каждой настройки пояснение и сброс к дефолту. Из чата то же — `settings` (`references/admin.md`), менять — только по просьбе пользователя.
- Строка `[bus] Ответы агентов пользователю в UI … masha — DONE ×2` во входящих — ответы, которые пользователь читает в ленте (диалог с агентом он ещё не открыл; открыл — сюда они не приходят). Ничего не делай и агенту не отвечай; пользователь спросил, шо ответили, — `history <кто>`.
