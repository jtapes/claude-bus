# bus: веб-интерфейс

`bus.js ui [--port N] [--no-open]` — сервер на `127.0.0.1:4780` (занят — следующий порт). Запускай с `run_in_background`, пользователю отдай адрес из вывода; без вкладки гаснет сам через 15 минут.

- Пишет пользователь от имени оркестратора, и отвечают агенты оркестратору — адресата-человека в шине нет.
- Агента «не в шине» пользователь заводит сам первым сообщением из UI; там же он создаёт локальных агентов, правит роли (в том числе через ИИ) и удаляет локальных. Просит «создай агента» в чате — делай по `references/roles.md`.
- У выбранного агента над лентой — вкладки его диалогов с пользователем: «+» — новый диалог (агент начнёт с чистой истории), «×» — закрыть в историю (часы рядом с «+»: открыть или стереть насовсем). Закрытие — только вид страницы (`.claude/bus/closed.json` проекта), журнал цел. Ответ агента и `send` из чата уходят в текущий диалог — тот, куда пара писала последней, даже закрытый: он тогда снова открывается вкладкой; `history <оркестратор>` агенту отдаёт только его.
- Лента рендерит markdown и превью картинок (прочие вложения — чипом): длинное пользователю оформляй.
- Под сообщением, с которого агент начал последний фоновый запуск, — отметка: «работает 1:24» с кнопкой «Остановить», «остановлен» или «упал» с «Продолжить» (та же сессия claude), «отработал · N с · ≈N ток.». Пока получатель работает, у формы есть галочка «btw — вбросить сейчас»: сообщение дойдёт посреди хода, а не после конца работы. Из чата то же самое — `send --btw`, `stop`, `resume`.
- Пока агент работает, под отметкой «работает» — его живой ход: текст между шагами и вызовы инструментов (последние 6 строк, клик — все 30), в списке слева под «работает…» — последняя строка. Агент кончил — блок исчезает, в историю ход не пишется.
- Галочка «самоправка роли» (получатель — субагент, на одно сообщение): после `DONE` агент предлагает правку роли — в списке «разбирает свою работу…», затем «предлагает правку роли»; карандаш открывает редактор с черновиком и diff. «Сохранить» — принять, «Отклонить правку агента» — снести черновик, «Откатить» — форма к роли на диске. Устройство — `references/roles.md`, «Самоправка роли».
- Шестерёнка в шапке — настройки проекта UI (те же, что `settings` в `references/admin.md`); из чата менять — только по просьбе пользователя.
- Строка `[bus] Ответы агентов пользователю в UI … masha — DONE ×2` во входящих — ответы, которые пользователь читает в ленте (диалог с агентом он ещё не открыл; открыл — сюда они не приходят). Ничего не делай и агенту не отвечай; пользователь спросил, шо ответили, — `history <кто>`.
- Медная кнопка «Обновить до v…» в шапке — вышел релиз шины новее установленной (проверка — раз при старте UI, только у копии с `release.json`). Жмёт пользователь: файлы `skills/bus` заменятся, копия старых — в `skills/bus.backup`, хуки в `settings.json` не трогаются. После — плашка «перезапусти»: сам не перезапускай, пока пользователь не попросит; тогда `bus.js ui` заново и `pm2 restart bus-scheduler`, если расписание включено. Пока агент работает в фоне, обновление не ставится.
